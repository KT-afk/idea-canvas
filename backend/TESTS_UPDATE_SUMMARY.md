## 🧪 Test Details

### Connection Route Tests (`connection-route.test.ts`)

**Test Structure:**
- Uses **Vitest** with mocked services
- Mocks `connection-service` and `auto-connection-service`
- Uses `supertest` for HTTP request simulation
- Validates response formats (`{ data }` vs `{ error }`)

**Key Test Cases:**

```typescript
// Example: Testing AI feature flag
it('should accept useAI=true query parameter', async () => {
  const response = await request(app)
    .get('/api/boards/board-123/connections/suggest?useAI=true');
  
  expect(response.status).toBe(200);
  expect(autoConnectionService.suggestConnections)
    .toHaveBeenCalledWith('board-123', 0.2, true);
});
```

### Connection Model Tests (`CONNECTIONS.test.ts`)

**Test Structure:**
- Uses **in-memory SQLite** for fast integration testing
- Tests Sequelize model behavior with real database operations
- Validates foreign key relationships
- Tests cascade delete behavior

**Key Test Categories:**
1. **Model Creation** - Required/optional fields, UUID generation
2. **Validations** - Null checks, field requirements
3. **Relationships** - sourceCard, targetCard, board associations
4. **Cascade Delete** - Cleanup when cards/boards deleted
5. **Default Values** - isAutoGenerated, timestamps
6. **Timestamps** - createdAt, updatedAt behavior

## 🔧 Configuration

### Vitest Config (`vitest.config.ts`)

```typescript
export default defineConfig({
  test: {
    globals: true,
    environment: 'node',
    setupFiles: ['./src/__tests__/setup.ts'],
    exclude: [
      '**/node_modules/**',
      '**/dist/**',
      '**/models/*.test.ts', // Skip model integration tests
    ],
  },
});
```

**Why model tests are excluded:**
- Integration tests require database connection
- Slower than unit tests (setup/teardown overhead)
- Better suited for CI/CD with test database
