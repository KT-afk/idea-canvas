### 2. **useEffect Missing Dependencies** (Medium Priority)

**Issue:** Hook dependency array incomplete

```typescript
// ⚠️ CURRENT: Missing loadSuggestions from deps
useEffect(() => {
  if (isOpen && boardId) {
    loadSuggestions();
  }
}, [isOpen, boardId]); // ← Missing loadSuggestions

// ✅ BETTER: Include all dependencies
useEffect(() => {
  if (isOpen && boardId) {
    loadSuggestions();
  }
}, [isOpen, boardId, loadSuggestions]);

// 🎯 BEST: Wrap loadSuggestions in useCallback
const loadSuggestions = useCallback(() => {
  setRejectedSuggestions(new Set());
  refetch();
}, [refetch]);
```

**Impact:** Medium - Could cause stale closures  
**Fix:** 2 minutes  
**Priority:** ⭐⭐⭐ (Should fix)
