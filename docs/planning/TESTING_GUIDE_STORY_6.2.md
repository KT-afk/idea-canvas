## 🔍 What to Look For

### **✅ Success Indicators**
- [ ] Suggestions API returns relevant connections
- [ ] Confidence scores are between 0.0 and 1.0
- [ ] Reason explains shared keywords (e.g., "Both mention 'mobile'")
- [ ] Creating connection saves all fields (confidence, reason, isAutoGenerated)
- [ ] Retrieving connections returns new fields
- [ ] Manual connections have `isAutoGenerated: false`
- [ ] Auto-generated connections have `isAutoGenerated: true`

### **❌ Potential Issues**
- [ ] No suggestions returned (check card content, lower minConfidence)
- [ ] Confidence/reason fields are null (check route passes fields to service)
- [ ] Database errors (check migration ran successfully)
- [ ] Performance issues with 100+ cards (O(n²) algorithm)

## 📊 Algorithm Explanation

**How it works:**
1. Extracts keywords from each card (removes stopwords like "the", "and")
2. Compares keywords between card pairs
3. Calculates Jaccard similarity: `common_words / total_unique_words`
4. Generates human-readable reason
5. Filters by minConfidence threshold

**Example:**
```
Card A: "Build mobile app for productivity"
Keywords: [build, mobile, app, productivity]

Card B: "Learn React Native for mobile development"
Keywords: [learn, react, native, mobile, development]

Common: [mobile]
Total unique: [build, mobile, app, productivity, learn, react, native, development] = 8 words
Similarity: 1/8 = 0.125 (12.5%)
Reason: "Both mention 'mobile'"
```

## 🐛 Troubleshooting

### **Issue: No suggestions returned**
**Solution:**
- Lower `minConfidence` to 0.05
- Check cards have actual content (not empty)
- Ensure cards have common keywords

### **Issue: confidence/reason are null**
**Solution:**
- Check migration ran: `npm run db:migrate`
- Check columns exist: Use database client to inspect CONNECTIONS table
- Restart backend server

### **Issue: "Connection already exists" error**
**Solution:**
- This is expected behavior (prevents duplicates)
- Delete existing connection first, or use different cards
