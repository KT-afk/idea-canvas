# Story 6.4: Draw Connection Lines (SVG)

## 📋 **Story Overview**
**Goal**: Visualize connections between cards as SVG lines on the canvas

**User Story**: As a user, I want to see visual lines connecting related cards so I can understand the relationships between my ideas at a glance.

---

## ✅ **Acceptance Criteria**

1. **SVG Overlay**
   - [ ] SVG layer positioned over the canvas
   - [ ] Lines appear behind cards (lower z-index)
   - [ ] Lines update when cards are dragged
   - [ ] Lines scale with zoom level

2. **Line Styling**
   - [ ] Curved lines (bezier curves) for aesthetics
   - [ ] Arrow indicators showing direction
   - [ ] Color-coded by confidence (high/medium/low)
   - [ ] Hover effect to highlight line

3. **Interactivity**
   - [ ] Click line to delete connection
   - [ ] Hover shows connection details (tooltip)
   - [ ] Lines update in real-time during drag

4. **Performance**
   - [ ] Efficient rendering (only visible connections)
   - [ ] Smooth updates during drag
   - [ ] No performance issues with 50+ connections

---

## 🎯 **Technical Approach**

### **Architecture**
```
App.tsx
  ├── BoardCanvas
  │   ├── ConnectionLines (NEW)  ← SVG overlay
  │   └── Cards
```

### **Components to Create**

1. **`ConnectionLines.tsx`** - Main SVG container
   - Fetches connections for current board
   - Renders all connection lines
   - Handles zoom/pan transformations

2. **`ConnectionLine.tsx`** - Individual line component
   - Draws bezier curve from source to target
   - Renders arrow head
   - Handles hover/click interactions
   - Shows tooltip on hover

3. **`useConnections.ts`** (hook) - Data fetching
   - React Query hook for fetching connections
   - Mutation for deleting connections
   - Real-time updates

## 📐 **SVG Line Mathematics**

### **Calculate Line Endpoints**
```typescript
// Get center of source card
const sourceX = sourceCard.positionX + (cardWidth / 2);
const sourceY = sourceCard.positionY + (cardHeight / 2);

// Get center of target card
const targetX = targetCard.positionX + (cardWidth / 2);
const targetY = targetCard.positionY + (cardHeight / 2);
```

### **Bezier Curve Path**
```typescript
// Quadratic bezier curve for smooth lines
const midX = (sourceX + targetX) / 2;
const midY = (sourceY + targetY) / 2;

// Control point offset (perpendicular to line)
const controlX = midX;
const controlY = midY - 50; // Curve upward

const path = `M ${sourceX},${sourceY} Q ${controlX},${controlY} ${targetX},${targetY}`;
```

### **Arrow Head**
```typescript
// Calculate arrow angle
const angle = Math.atan2(targetY - sourceY, targetX - sourceX);

// Arrow head as polygon
<polygon 
  points="0,-5 10,0 0,5"
  transform={`translate(${targetX},${targetY}) rotate(${angle * 180 / Math.PI})`}
/>
```

## 🎨 **Styling & Colors**

### **Confidence-Based Colors**
```typescript
function getConnectionColor(confidence: number | null): string {
  if (!confidence) return '#94a3b8'; // Neutral gray
  if (confidence >= 0.3) return '#10b981'; // Green (high)
  if (confidence >= 0.15) return '#f59e0b'; // Yellow (medium)
  return '#3b82f6'; // Blue (low)
}
```

### **Line Styles**
- **Stroke width**: 2px default, 3px on hover
- **Opacity**: 0.6 default, 1.0 on hover
- **Dash pattern**: Solid for auto-generated, dashed for manual
