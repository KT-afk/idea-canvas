# Story 6.3: Connection Suggestions UI

**Epic:** 6 - Connections & Relationships  
**Status:** In Progress

## 🎯 Goal

Build a user-friendly interface for viewing, accepting, and rejecting auto-generated connection suggestions.

---

## 📋 Acceptance Criteria

- [ ] "Find Connections" button in board toolbar
- [ ] Suggestions panel/modal displays potential connections
- [ ] Each suggestion shows:
  - [ ] Source card preview
  - [ ] Target card preview
  - [ ] Confidence score (visual indicator)
  - [ ] Reason explanation
  - [ ] Accept button (✓)
  - [ ] Reject button (✗)
- [ ] Accept action creates connection and updates UI
- [ ] Reject action removes suggestion from list
- [ ] Loading state while fetching suggestions
- [ ] Empty state when no suggestions found
- [ ] Success/error toast notifications
- [ ] Suggestions panel can be closed
- [ ] Re-fetch suggestions after accepting/rejecting

## 🔌 API Integration

### Fetch Suggestions
```typescript
GET /api/boards/{boardId}/connections/suggest?minConfidence=0.15
```

### Accept Suggestion (Create Connection)
```typescript
POST /api/boards/{boardId}/connections
Body: {
  sourceCardId,
  targetCardId,
  confidence,
  reason,
  isAutoGenerated: true
}
```

### No "Reject" API
- Just remove from UI state
- Optional: Store rejections in localStorage to avoid re-suggesting

## 💡 UX Considerations

### When to Show Button
- Always visible (enabled when board has 2+ cards)
- Badge shows suggestion count (fetch on mount)
- Click opens panel

### Auto-Trigger
- Optional: Auto-open panel if board has 5+ cards and 0 connections
- Toast: "💡 We found 3 potential connections. [View]"

### Performance
- Fetch suggestions lazily (on button click, not on mount)
- Cache suggestions for 5 minutes
- Re-fetch after accepting/rejecting

### Feedback
- Toast on accept: "✓ Connection created"
- Toast on error: "✗ Failed to create connection"
- Animate suggestion card out when accepted/rejected
